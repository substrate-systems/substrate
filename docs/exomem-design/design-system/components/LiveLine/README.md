# LiveLine

A live line: an amber dot that blinks while something is live, beside what is happening, in one line of mono.

**You provide** `text`, `live`, and `onToggle` for the Pause / Resume ghost button. Paused: the dot goes grey and still. New text cross-fades in.

**Use it** on Home and in the viewer header for live activity. Amber here means it is truly live; when there is no real feed, don't show one.
