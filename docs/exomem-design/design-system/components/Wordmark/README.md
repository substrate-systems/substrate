# Wordmark

The logo: the word Exomem with the Dot E as its capital, and every `Mark` state working inside it.

**Use it** wherever the name fits: page headers (17 px tall), emails, the status page. While the app boots, `state="working"`; on the checkout page it can mirror the payment's steps; when Exomem can't be reached, `state="off"`.

**You provide** `height` (px), and the same `state`, `steps`, `step`, `value`, `label` as `Mark`. `breathe` is off by default here: a header logo holds still at rest.

**Don't** redraw it, set it in a font, outline it, or put the Mark beside it (the E would be said twice). The geometry is the brand kit's `exomem-wordmark-initial.svg`.
