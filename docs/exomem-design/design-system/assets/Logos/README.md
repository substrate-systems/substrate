# Logos

The wordmark is the logo: the Dot E is the capital E of *Exomem*. Type is IBM Plex Mono 500 converted to outlines; every viewBox hugs its ink. In product UI, use the `Wordmark` component (it animates); use these files for static places (emails, documents, other people's sites).

- `exomem-wordmark-initial.svg` — **the logo**, on dark grounds. Inks: fg-primary `#ECE9E2`, amber `#FFB000` (the middle row).
- `exomem-wordmark-initial-on-light.svg` — the logo on light grounds. Inks `#1A1814` and `#A86E00`.
- `exomem-wordmark-initial-small.svg`, `-small-on-light.svg` — below 22 px text height (the small cut E).
- `exomem-wordmark-initial-mono.svg` — single ink `#ECE9E2`, for one-colour use on dark; recolour the file for other single inks.
- `exomem-lockup.svg`, `-on-light.svg` (horizontal), `exomem-lockup-stacked.svg`, `-on-light.svg` — mark and name in one image, only where a place demands both.
- `exomem-wordmark.svg`, `-on-light.svg` — the name alone in plain type (single ink `#ECE9E2` / `#1A1814`), for rare places where the Dot E can't render.

Never redraw, outline or gradient the logo; never set the name in a font beside the mark. Clear space: the height of the middle row on every side.
