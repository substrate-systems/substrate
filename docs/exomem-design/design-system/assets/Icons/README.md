# Icons

Browser and home-screen icons. All sit on the dark tile (`#14120F`) so they read on light and dark tab bars; app icons are always the dark tile, even on light pages.

- `favicon.svg` — the tab icon (inks `#14120F` tile, `#ECE9E2`, `#FFB000`).
- `favicon-16.png` (pixel-exact), `favicon-32.png`, `favicon-48.png` — raster fallbacks.
- `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` — home screens and the PWA manifest.

Not here: `favicon.ico` and `site.webmanifest` (the store takes images only); both are in the brand kit zip in the handoff.
