# Email

The web band at the top of each email, one per account state (1200 × 240, shown at 600):

- `band-arrive.png` — sparse, one amber light arriving (welcome).
- `band-live.png` — links amber-tinted, busy notes lit (active).
- `band-readonly.png` — intact, one light held (read-only).
- `band-kept.png` — intact, grey (ended, kept).
- `band-fading.png` — the far end thinning (deletion scheduled).
- `band-gone.png` — the ghost only (deleted).
