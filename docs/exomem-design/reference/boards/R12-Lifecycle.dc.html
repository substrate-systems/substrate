How long is it read-only?
Today: for as long as Paddle keeps the subscription "past due", which is set in Paddle, not in our code. Proposal: set Paddle's retries to {{ d.graceDays }} days and say that number everywhere, on the page and in the email.
How long do we keep it after?
The code already says 30 days, fixed on purpose after the security review. Keep it: with export one click away and a reminder a week out, 30 is fair. Longer mostly means storing memories nobody comes back for.
Export, always
Export works in every state until deletion: read-only, ended, paused, even suspended. Paused keeps the memory for as long as it’s paused. Paddle sends its own receipts; we don’t duplicate them.
