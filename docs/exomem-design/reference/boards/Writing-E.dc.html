The E writes itself, for any number of steps
The pen runs the letter the way you would draw it: top bar, down, the middle row, down, the bottom bar. Steps split that stroke. Up to five steps, each one ends on a corner of the letter; more than five split it evenly, and a step can end part-way through a dot. Every state is a number the browser animates, so a step finishing is the pen moving on, never a swap.
