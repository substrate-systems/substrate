# Exomem directory reviewer demo

`/exomem/directory-review-0.102.5.mp4` is a short, silent recording of native
ChatGPT results from the dedicated synthetic directory-review sample on Exomem
Cloud 0.102.5. It shows an explicit synthetic save result and independent
recovery of the new conclusion in a separate chat.

The recording is edited to remove waiting. It is not an uncut sign-in or write
walkthrough. Browser tabs, credentials and the account sidebar are excluded.
The independent sample MCP read confirmed the stored conclusion after the
native save. No personal vault data or payment flow is included.

The file is a public static asset. A normal merge to `main` publishes it through
the existing Vercel deployment. Verify anonymous playback and HTTP range access
before using its URL in directory review materials. Removing the asset in a
normal follow-up deployment withdraws it; change any directory references too.

This demo does not establish native Claude acceptance, clickable citations,
adversarial tenant-isolation testing, or permission to submit either listing.
Both directory submissions remain held for publisher review.
