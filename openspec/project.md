# Substrate OpenSpec Project

This directory contains behavioral specifications for the Substrate landing page.

## Structure

- `specs/` - Behavioral specifications
- `changes/` - Change proposals and tracking

## Usage

```bash
# List all specs
npm run openspec:list

# Validate specs
npm run openspec:validate
```

## Exomem Cloud load target

Exomem Cloud plans for 10,000 tenants. A plan for a user-facing route, job or query cites this target, the size of the data it touches and a latency budget.
